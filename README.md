# Helfy Marketing Web Master — Test Assignment

Responsive landing page implementation based on the provided Figma design.

## Technologies

* HTML5
* CSS3
* Vanilla JavaScript
* SVG and image assets

No frameworks or external libraries were used.

## Implemented

* Responsive header and trust bar
* Hero section with benefits and CTA
* Testimonials carousel with navigation and pagination
* "How it works" section with responsive slider
* Footer
* Responsive layouts for desktop and mobile
* Interactive carousel/slider functionality using Vanilla JavaScript


## How to Run

No installation or build process is required.

Open `index.html` directly in a browser or use a local development server such as VS Code Live Server.

## Project Structure

